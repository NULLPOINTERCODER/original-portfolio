# 🚀 Vishal's Dev Den | Full Stack Portfolio

Welcome to my personal portfolio! This is a modern, high-performance web application designed to showcase my skills, projects, and live coding performance metrics.

## ✨ Features

- **Live Data Integration**: Dynamically fetches LeetCode, CodeChef, and total problem count from Codolio.
- **Auto-Advancing Carousels**: Sleek, one-card-at-a-time focus for Certifications and Projects with 3D flip animations.
- **Premium Animations**: Built with Framer Motion, featuring 3D hover effects, smooth transitions, and tactile feedback.
- **WhatsApp Integration**: Contact form redirects directly to WhatsApp with pre-filled details.
- **Modern UI/UX**: Dark-themed, responsive design with glassmorphism and vibrant accent glows.

## 🛠 Tech Stack

- **Frontend**: React 18, TypeScript, Vite
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion, Lucide React (Icons)
- **Data Fetching**: Custom fetch hooks with Vite Proxy for Codolio API

## 🚀 Getting Started

1. **Clone the repository**:
   ```bash
   git clone https://github.com/NULLPOINTERCODER/Personal-Portfolio.git
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Run the development server**:
   ```bash
   npm run dev
   ```

4. **Build for production**:
   ```bash
   npm run build
   ```
